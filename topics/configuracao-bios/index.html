1. Sequência POST e Diagnóstico por Debug LEDs

Ao ligar o PC, o firmware executa o POST (Power-On Self-Test), verificando energia, CPU, memória, placa de vídeo e dispositivos de boot antes de entregar o controle ao sistema operacional.

ETAPAS TÍPICAS DO POST E DIAGNÓSTICO (DEBUG LEDs) CPU → DRAM → VGA → BOOT
  • LED / código travado em DRAM: Reassente os pentes de memória, teste em slots recomendados (ex.: A2/B2) e aguarde o memory training (especialmente em DDR5 ou após reset de CMOS).
  • LED / código travado em VGA: Confira alimentação auxiliar da GPU, encaixe no slot PCIe x16 e cabo de vídeo ligado à placa de vídeo (não à placa-mãe, salvo diagnóstico com vídeo integrado).

2. Ajustes Essenciais na UEFI Após o Primeiro Boot

Opção UEFI Função Observação Prática
XMP / EXPO / DOCP Aplica frequência e timings do kit de memória Ative após confirmar estabilidade inicial do sistema
Resizable BAR / Smart Access Memory Permite à CPU acessar blocos maiores da VRAM da GPU Requer suporte da CPU, placa-mãe, GPU e modo UEFI/Above 4G Decoding
Modo de Boot (UEFI / GPT) Define inicialização moderna via UEFI Padrão recomendado para sistemas atuais e recursos de segurança (ex.: fTPM/Secure Boot)

3. Curvas de Fan e Ordem de Boot

  • Curvas de ventoinha (PWM vs. DC): Ventoinhas de 4 pinos usam controle PWM; ventoinhas de 3 pinos usam controle por tensão (DC). Ajuste curvas graduais para equilibrar ruído e temperatura.
  • Ordem de boot: Coloque o pendrive instalador em primeiro apenas durante a instalação do SO; depois, priorize o SSD com o sistema operacional.

4. Simulador Interativo de UEFI / POST

Simule o estado de boot e os parâmetros da UEFI ajustando versão de BIOS, encaixe de RAM, cabo de vídeo e opções de desempenho.
